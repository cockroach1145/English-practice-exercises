# 英语练习

一个基于命令行的英语「中译英」随机刷题小程序。题库按模块组织，运行时随机打乱顺序，逐题作答并即时判分。

## 功能特点

- 题库按 4 个模块分类（动词短语、介词搭配、名词短语、写作句型）
- 每次运行都会打乱各模块内部顺序，再合并成一套题
- 实时判分，答对 +1
- 答错时展示正确答案，并要求照着仿写一遍
- 可选查看该题的知识点提示
- 结束后输出总得分

## 目录结构

```
/
├── run.py      # 主程序：随机出题、答题交互、判分
├── 题库.py     # 题库数据：module_1 ~ module_4
└── README.md   # 项目说明
```

## 运行环境

- Python 3.8+（仅使用标准库 `random`，无第三方依赖）

## 使用方法

在项目根目录执行：

```bash
python run.py
```

运行后会依次显示题目，按提示作答；答错时按要求仿写一次，并可选择是否查看知识点。

## 题库格式

题库文件 `题库.py` 中每个模块是一个列表，每道题为字典：

```python
{"type": "中译英", "question": "拜访；号召", "answers": "call on", "knowledge": "动词短语"}
```

| 字段 | 说明 |
| --- | --- |
| `type` | 题目类型 |
| `question` | 题干，即中文释义 |
| `answers` | 标准答案；多个可接受答案用 `&` 分隔，如 `arrive at&arrive in` |
| `knowledge` | 知识点提示，可为空字符串 |

判分规则：用户输入去掉首尾空格并转为小写后，与 `answers` 按 `&` 拆分的任一答案完全一致即算正确。

## 如何扩充题库

1. 在 [题库.py] 对应模块列表中按上述格式追加字典即可；
2. 如需新增模块，添加 `module_5` 并在 [run.py] 的 `all_modules` 中登记。

## 说明

- 判分为精确匹配（忽略大小写，但不容错拼写），`call on` 与 `call on.` 会被视为不同答案；
- 作答不能为空，空输入会要求重新输入；
- 每次运行题量等于题库中所有模块的题目总和。
